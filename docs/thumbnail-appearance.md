# Thumbnail appearance

[Back to README](../README.MD) · [Settings overview](settings.md)

## Appearance

Open **Thumbnails → Appearance** for text visibility, an installed-font selector, font size, text color, label insets, opacity, background and active/inactive border styling. Numeric ranges and units are shown beside the fields. Color fields accept RGB hex, supported named colors or RGB components from 0 to 255. Choose opens the standard Windows color dialog; a swatch previews the accepted color.

Opacity is 0–100%; 0 makes thumbnails invisible. The tray and Settings remain recovery paths. Inactive-border controls explain their dependency on showing inactive/group borders.

The border-layout dropdown and diagram describe event-inside/active-outside, active-inside/event-outside and a combined border. Active/event thickness applies to those rings; inactive/group styling is retained. Test thumbnail previews draft changes before they are applied.

## Labels and character overrides

**Thumbnails → Labels** contains anonymous names and a table of original-character/displayed-name pairs. Blank replacement text retains the original label. A row is inserted or removed as a complete pair. Anonymous names take priority while enabled.

**Character appearance** provides per-character active-border, inactive-border and label colors in one row. The master checkbox enables those overrides; rows can be prepared before enabling them. Pick colors from each row editor. Character names and all three colors remain paired during edits and removal.

Minimum dimensions are in **Thumbnails → Layout**. The default size cannot be smaller than the configured minimum. All appearance changes remain staged until **Apply & restart**.
