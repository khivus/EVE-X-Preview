# Focused recheck for the final v1.7.0.4 additions

The earlier Settings UI review is covered by [its existing checklist](../settings-review-recheck.md). For the latest additions, check these paths:

For the recovery/reconnect/held-switching follow-up, prioritize these checks:

* Open the main app once: recovery guidance should suggest a readable saved copy when one exists and offer backup/app folders plus GitHub and Discord. Reopening should not repeat the first-launch notice.
* Edit a non-default profile and Apply twice. Settings should recover its connection automatically, retain that profile and show the saved values. A short connection gap during the runtime restart is expected; manual Reconnect remains available after five failed attempts.
* With three live EVE clients, hold a character-group or Quick Group key at a 30 ms interval. Cycling should progress while thumbnails keep updating. Switch directly between EVE clients with the border-clear delay set high: the old active border should clear and the new border should appear promptly. Alt-Tab away from EVE should still use the configured delay.
* Use command hotkeys for pause/resume, visibility, click-through and live previews. Each should briefly confirm its resulting state; a new message should replace the old one. Reload/Exit should acknowledge the request and still protect a settings draft. Window switching and thumbnail mouse gestures should stay quiet.

1. **Startup backups:** open the application once, then use About → Open settings backups in either editor. Its installation-specific folder should contain a new settings snapshot and at most five automatic snapshots. Existing pre-migration copies should be moved there from the application folder and retained separately; new migration/recovery archives also go there.
2. **Focused border:** under Thumbnails → Appearance, set the clearing delay to 2000 ms and Apply. Switch from EVE to another application: the last active border should remain briefly, then clear. Returning before the delay expires should keep it; switching directly to another EVE client should move the highlight immediately. Set 0 for immediate clearing.
3. **Group hold timing:** under Switching → Switching behavior, set 30 ms and Apply. It should save successfully and allow faster repeated group switching while the shortcut is held. Other configured delay values should remain unchanged.
4. **Pause modes:** assign distinct shortcuts under Switching → Keyboard shortcuts. Pause EVE switching and confirm character/group switching stops while utility, profile and non-EVE shortcuts still work. Resume it, then test Pause all hotkeys: utility and switching hotkeys should stop, and the same full-pause shortcut should resume them. Check the corresponding optional tray entries and their check marks. The two pause states are independent.
5. **Shared Quick Group shortcut:** share CapsLock between Quick Group and a direct character/group shortcut. With Quick Group empty, the direct shortcut should run; if its character is unavailable, the character group should run. Add a window to Quick Group: it should take priority. Remove or close its last window: fallback should return.
6. **Changelog:** About → Read included changelog should begin with v1.7.0.4. The [short announcement](v1.7.0.4-summary.md) is ready to copy.

Automated checks cover retention, byte-preserving snapshots, backup failure handling, delay/reset timing, minimum-value validation, both pause modes, real AHK priority dispatch with synthetic windows, and Settings control exposure. Real EVE focus timing, held-key repeat cadence and the user's CapsLock/window setup still need the brief live checks above.
