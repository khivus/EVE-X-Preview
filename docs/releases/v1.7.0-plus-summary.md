**EVE-X-Preview v1.7.0+**

## Changes
- Rebuilt Settings with search, clearer categories and a resizable layout that remembers your position.
- Added draft editing with Apply/Discard and protection against losing unsaved changes.
- Added spreadsheet-style assignment tables with copy/paste, keyboard navigation and removal undo.
- Added inheritance per settings section and editing Default without switching profiles.
- Redesigned event settings and the shared sound library.
- Added an optional standalone C# Settings editor alongside the built-in editor.
- Added shared themes, including Graphite, Matrix, Kitsune, Synthwave and Cyberpunk.
- Added automatic settings backups, recovery guidance and reconnect after Apply.
- Improved shortcut conflict reporting, profile editing and thumbnail refresh during held switching.
- Added off-screen thumbnail recovery under Layout.
- Added full portable-package updates with rollback and offline recovery.
- Reduced event-sound startup delay and fixed rapid table-cell editing and clipped Settings text.
