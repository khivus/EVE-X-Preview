**EVE-X-Preview v1.7.0+**

Settings has been rebuilt with search, clearer categories, profile inheritance, draft editing with Apply/Discard, editable assignment tables and a redesigned event/sound library. An optional standalone C# editor adds modern controls and shared themes alongside the built-in editor. The follow-up updates add automatic backups and recovery guidance, reconnect after Apply, clearer hotkey controls, Quick Group shortcut sharing and thumbnail refresh while switching keys are held.
