# Character list manual verification

Open Settings > Thumbnails > Character list and enable Show character list, then Apply (restart if the editor requests it).

- With several EVE clients open, verify every client appears, including clients whose thumbnails are hidden. Click each entry: the correct client should focus and its list marker should highlight. Check existing thumbnail clicks and switching shortcuts still work.
- Hide thumbnails globally and for individual characters: the list should stay available. Disable the list: thumbnails should retain their existing behavior.
- Use the top-left arrow twice: only the list body should collapse and expand. Move using the title bar and resize from the edges. Restart: position, expanded height, column width and collapsed state should persist.
- Set two or three columns and a column width; compare vertical and horizontal fill directions. Resize and use the mouse wheel with more clients than fit: all entries should remain reachable.
- Choose A–Z, Z–A, oldest client and newest client sorting. Start clients in a known sequence and verify age ordering. Drag an entry onto another: it should move there, select Custom order and retain that order after restarting. Switch to another sort to reset the order.
- Open and close clients and log characters in and out: labels and membership should update without stale rows. Verify duplicate login-screen labels still activate their respective windows.
- Change the settings theme among light, dark, system and custom palettes, then Apply: list background, text and active marker should follow the saved theme. Check readability on each monitor and display scale used.

Automated checks cover configuration validation/persistence, sorting and the no-client window lifecycle. Live EVE switching, mouse interaction, multi-monitor placement and appearance require the checks above.
