# Character list quick checks

- Settings > Thumbnails: Appearance opens first; Character list follows Automatic placement. Categories and groups have distinct icons in both editors.
- Profile inheritance: inherit Character list from Default, then customize it in another profile. Enabled state, options, order and placement should follow the selected source.
- Enable the list: there is no Windows title bar/close button. Switch EVE clients: the selected row has a filled background and bold label; rows update without the window disappearing.
- Drag the Characters heading to move; resize edges down to 50 px columns. Collapse/expand and scroll overflowing rows. Drag entries: the tooltip identifies the source and hovered row marks the destination; release to reorder.
- Use the three-dot menu: toggle Always on top, Lock position and Auto save position; select sort, opacity and fill direction. Verify the same values in Settings and after restart. With autosave off, moving should not replace the saved position.
- Open multiple logged-out clients: enable HWND labels to tell them apart. With grouping enabled, they sort last in A–Z and first in Z–A. Custom drag order should remain usable.
- Enable grouping by system with EVE chat logging enabled: characters in the same known system stay together and labels update after jumps; missing logs show Unknown system.
- Hide on lost EVE focus: another application hides the list, returning to EVE restores it. Hidden thumbnails remain independent; existing thumbnail switching and shortcuts still work.

Live EVE interaction, drag feedback, focus behavior, menu appearance and display scaling require manual verification.
