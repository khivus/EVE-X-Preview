# EVE window settings

[Back to README](../README.MD) · [Settings overview](settings.md)

**EVE windows → Activation and placement** contains minimizing other clients after switching, its delay, maximizing activated clients and restoring saved window placement. Delay accepts 50–60000 ms and is available when automatic minimizing is enabled.

**Capture open EVE window placement to draft** records the visible client windows for the editing profile. It does not activate or restore minimized clients; their previous saved placements are kept. Apply & restart saves the captured placement.

**Close protection** consolidates exceptions for login screens, the focused client, characters excluded from groups and Quick Group members. These protect against **Close all EVE windows**; directly closing one client remains possible.

**Close protection → Character exceptions** uses one row per character with independent **Never auto-minimize** and **Protect from Close all** columns. Add names manually or choose running EVE windows. Removing a row offers Undo. Every setting remains staged until Apply & restart.
